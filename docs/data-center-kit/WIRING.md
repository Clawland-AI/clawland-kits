

# Wiring Guide for Monitoring Kit

## Step 1: Connect Sensors to Main Unit
1. **Temperature Sensors**: Connect each temperature sensor to the main monitoring unit using the provided data cables. Ensure the sensors are securely fastened to their designated locations.
2. **Humidity Sensors**: Follow the same procedure as for temperature sensors, connecting each humidity sensor to the main unit.

## Step 2: Power Connections
1. **Power Supply**: Connect the power supply unit to the main monitoring unit using the provided power cable. Ensure the power supply is rated for the total load of all connected devices.
2. **Backup Power**: Connect the backup power source (if applicable) to the main unit to ensure continuous operation during power outages.

## Step 3: Network Connections
1. **Network Interface Card (NIC)**: Connect the NIC to the main unit and ensure it is properly configured with the correct IP settings.
2. **Network Cable**: Connect the NIC to the network switch using an Ethernet cable.

## Step 4: Cooling System Integration
1. **Cooling Controller**: Connect the cooling system controller to the main monitoring unit using the provided data cable.
2. **Cooling Fans**: Connect the cooling fans to the cooling controller and ensure they are properly aligned and secured.

## Safety Warnings
- **Electrical Safety**: Always disconnect power sources before performing any wiring or connections.
- **Sensor Placement**: Ensure sensors are placed in areas that accurately reflect the environment they are monitoring.
- **Cable Management**: Keep cables organized and away from potential hazards to prevent tripping or damage.
- **Professional Installation**: If unsure about any wiring steps, consult a professional to ensure proper installation and safety.
